# Signal Processing

Signal processing is an important part of AquaSense because the project does not only generate different SONAR waveforms; it also needs a way to inspect and characterize those waveforms during development.

The signal-processing workflow is used to verify the generated signal, compare waveform modes and study how the selected waveform behaves in the time and frequency domains.

## Signal-Processing Flow

```text
Selected Waveform
       ↓
Digital Sample Sequence
       ↓
DAC / Physical Output
       ↓
Oscilloscope Capture
       ↓
Sampled Signal Data
       ↓
FFT / Spectrum / Spectrogram
       ↓
Waveform Characterization
```

## Analysis Methods

### Time-Domain Analysis

The time-domain waveform can be inspected for:

- Overall waveform shape.
- Amplitude behaviour.
- Pulse duration.
- Frequency-sweep progression.
- Timing consistency.
- Transitions between configured waveform modes.

### FFT

The Fast Fourier Transform provides a frequency-domain representation of the sampled signal. It can be used to inspect the dominant frequency components and compare the expected waveform spectrum with the measured output.

### Spectrum Analysis

Spectrum analysis helps identify the frequency content associated with each waveform mode and provides a common basis for comparing LFM, HFM, PCP and geometric-sweep signals.

### Spectrogram

A spectrogram represents frequency content as it changes over time. This is particularly useful for frequency-swept signals because it provides a visual representation of the sweep behaviour.

### Performance Metrics

Once experimental data is available, performance metrics can be defined for comparing waveform modes. Candidate measurements include:

- Frequency accuracy.
- Sweep behaviour.
- Signal amplitude consistency.
- Timing consistency.
- Spectral characteristics.
- Processing requirements.

Only validated measurements should be reported as experimental results.

## Signal Model

A general transmitted signal can be represented as:

$$s(t)=A(t)\cos\left(2\pi\int_0^t f(\tau)\,d\tau+\phi\right)$$

where $A(t)$ is the amplitude envelope, $f(t)$ is the instantaneous frequency and $\phi$ is the phase term.

For Linear Frequency Modulation (LFM):

$$f(t)=f_0+kt$$

where $f_0$ is the starting frequency and $k$ is the frequency-sweep rate.

## Waveform Analysis by Mode

### LFM

LFM analysis focuses on whether the generated signal follows the intended linear frequency progression over the configured transmission interval.

### HFM

HFM analysis focuses on the generated frequency progression and its time-frequency representation. The spectrogram is useful for visual inspection of the changing frequency trajectory.

### Phase-Coded Pulses (PCP)

PCP analysis focuses on pulse structure, timing and the configured phase-code sequence. The measured waveform can be compared with the expected digital sample pattern.

### Geometric Sweep

Geometric-sweep analysis focuses on whether the generated frequency progression follows the intended non-linear sweep behaviour.

## Digital vs Physical Verification

AquaSense should distinguish between the waveform generated by firmware and the waveform observed from the physical hardware.

```text
Firmware Samples
      ↓
Expected Digital Waveform
      ↓
DAC + Analog Chain
      ↓
Measured Electrical Waveform
      ↓
Oscilloscope
      ↓
FFT / Spectrogram
      ↓
Comparison
```

This comparison helps identify differences introduced by sampling, DAC behaviour, filtering, amplification and other hardware stages.

## Processing Considerations

The embedded implementation may use CMSIS-DSP and the MCU floating-point capability for signal-processing operations where required. FFT processing and waveform characterization can also be performed offline during development when appropriate.
