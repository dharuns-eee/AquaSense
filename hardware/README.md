# Hardware

AquaSense is designed as a SONAR transmitter payload/subsystem for an AUV.

## Main Hardware

- STM32G4-series MCU
- SAR ADC
- 12-bit high-speed DAC
- Low-pass filter
- Class-D amplifier + MOSFET stage
- Underwater acoustic transducer

## Validation Setup

Prototype signal output can be inspected using an oscilloscope. Sensor-condition inputs can be used during initial adaptive-decision validation.

Controlled underwater testing and AUV integration are planned next.
