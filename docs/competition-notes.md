# Competition Notes

## Project

**AquaSense: Adaptive SONAR for AUVs**

## Positioning

A low-power, real-time adaptive SONAR transmitter payload for Autonomous Underwater Vehicles.

AquaSense is a SONAR subsystem/payload intended to be integrated into an AUV, not a complete AUV platform.

## Core loop

**Sense → Decide → Adapt → Transmit → Analyse & Feedback**

## Main innovation areas

- Software-defined waveform generation
- Environment-aware waveform selection
- Battery-aware transmission control
- Hardware-assisted real-time waveform streaming
- Closed-loop signal analysis and feedback

## Evidence policy

Only measured or otherwise validated experimental results should be added to the results directory. Design targets, planned tests, and future work should be clearly labeled as such.
