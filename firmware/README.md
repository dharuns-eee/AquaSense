# Firmware

Embedded firmware for the AquaSense SONAR transmitter payload.

## Planned / Prototype Modules

- Adaptive decision logic
- LFM / HFM / PCP / geometric waveform generation
- Look-Up Tables (LUTs)
- DAC output control
- DMA-driven waveform streaming
- Hardware timer control
- NVIC priority interrupts
- CMSIS-DSP / FPU signal processing
- WFI-based CPU duty-cycling

Firmware source files will be added as the embedded implementation is organized and validated on hardware.
